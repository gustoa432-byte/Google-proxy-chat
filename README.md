# ⚡ Gemini Proxy Chat (v2.1)

> **Ультралёгкий, производительный и модульный веб-прокси чат для Google Gemini API.**  
> Оптимизирован для бесплатного тарифа Render.com (потребление RAM < 40 МБ, один автономный процесс Node.js, без тяжёлых сборщиков).

---

## 🚀 Основные возможности

- 🌊 **Настоящий Realtime Streaming (SSE):**
  - Поддержка `streamGenerateContent` по протоколу Server-Sent Events.
  - Посимвольный живой вывод ответа модели с мигающим курсором.
  - Вывод метаданных токенов (`usageMetadata`) в конце каждого ответа.
- 🔑 **Два режима доступа (BYOK + Owner PIN):**
  - **BYOK (Bring Your Own Key):** любой пользователь может указать личный ключ Google AI Studio прямо в интерфейсе. Ключ сохраняется исключительно в `localStorage` браузера, передаётся по защищённому заголовку `x-gemini-api-key` и **никогда не сохраняется на сервере** и не пишется в логи.
  - **Owner PIN:** владелец сервера может задать серверный `GEMINI_API_KEY` и защитить его через `ACCESS_PIN`. Доверенные пользователи могут вводить PIN в настройках и использовать квоту сервера без личного ключа.
- ⏹️ **Кнопка «Прервать генерацию» (Abort / Cancel):**
  - Во время стриминга кнопка «Отправить» трансформируется в кнопку «⏹ Прервать».
  - По клику клиент немедленно отменяет `fetch` через `AbortController` и разрывает upstream-запрос к Google API, сохраняя полученную часть ответа с пометкой *(генерация остановлена)*.
- 🎛️ **Управление Temperature & Max Output Tokens:**
  - Ползунок температуры от `0.0` (строгий/аналитический) до `2.0` (креативный), по умолчанию `0.7`.
  - Выбор лимита токенов: авто / 2048 / 4096 / 8192.
  - Настройки сохраняются между перезагрузками страницы.
- ✂️ **Контроль размера истории и экономия токенов:**
  - Индикатор количества сообщений в диалоге.
  - Предупреждающий баннер при превышении 40 сообщений.
  - Кнопка «Обрезать историю» с выбором сохранения последних 10, 20 или 30 сообщений.
- 🔄 **Интеллектуальный Fallback моделей:**
  - Поддержка актуального стека моделей: `gemini-3.5-flash`, `gemini-3.6-flash`, `gemini-3.7-flash`, `gemini-3.8-flash`, `gemini-2.5-pro`, `gemini-2.5-flash`, а также кастомных моделей.
  - При ошибках `404`, `503` или `429` запрос автоматически переключается на следующий рабочий кандидат. При `401`/`403` cascade останавливается сразу, предотвращая бессмысленный расход запросов.
- 🎨 **Темизация и адаптивный дизайн:**
  - Мгновенное переключение тем (☀️ Светлая / 🌙 Тёмная) с сохранением в `localStorage`.
  - Удобный интерфейс для смартфонов и ПК.
- 📎 **Мультимодальность:**
  - Загрузка изображений (PNG, JPEG, WebP, GIF) с предпросмотром.
  - Загрузка текстовых документов, логов и исходного кода (TXT, MD, JS, PY, JSON, CSV и др.).
- 🧠 **Системные инструкции (System Prompt):**
  - Готовые пресеты (Универсальный, Senior Developer, Редактор, Краткий) + поле для произвольного промпта.
- 📥 **Экспорт в Markdown:**
  - Выгрузка всего диалога в файл `.md` в один клик.
- 🛡️ **Безопасность и стабильность:**
  - Отсутствие shadowing переменных ответа `res`.
  - Защитные заголовки: `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin`.
  - Встроенный rate-limiter: 40 запросов в минуту с одного IP.
  - Лимит размера тела запроса: 25 МБ.

## 🏃 Быстрый старт

### 1. Требования
- Node.js 18+

### 2. Установка
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd gemini-proxy-chat
npm install
```

### 3. Тестирование
```bash
npm test
```
*Запускает модульные тесты через встроенный тест-раннер Node.js.*

### 4. Запуск
```bash
npm start
```
Сервер запустится на `http://localhost:3000`.

## ☁️ Деплой на Render.com (Free Tier)

1. Зарегистрируйтесь на [Render.com](https://render.com).
2. Выберите **New +** → **Web Service**.
3. Подключите Git-репозиторий.
4. Укажите параметры:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** `Free` (512 MB RAM)
5. В разделе **Environment Variables**:
   - `PORT`: `3000` (или оставьте стандартный Render)
   - `ACCESS_PIN` *(опционально)*: секретный PIN для владельца (например, `4921`)
   - `GEMINI_API_KEY` *(опционально)*: серверный ключ Google AI Studio
6. Нажмите **Deploy Web Service**.

> 💡 **Keep-Alive на бесплатном тарифе Render:**
> Бесплатные инстансы засыпают после 15 минут неактивности. Используйте сервис мониторинга (UptimeRobot, Cron-Job.org), отправляя `GET`-запрос на эндпоинт `https://<ваш-сервис>.onrender.com/ping` каждые 10 минут.

## 🔐 Схема авторизации: BYOK vs Owner PIN

```
                           +------------------------+
                           |   Клиент в браузере    |
                           +-----------+------------+
                                       |
                   +-------------------+-------------------+
                   |                                       |
                   v                                       v
         [ Режим 1: BYOK ]                       [ Режим 2: Owner PIN ]
   (Свой Gemini API Key пользователя)            (Серверный ключ владельца)
                   |                                       |
                   | Заголовок: x-gemini-api-key           | Заголовок: x-access-pin
                   v                                       v
      +---------------------------------------------------------+
      |                   Express Proxy Server                  |
      | - Проверяет PIN: совпадает -> использует GEMINI_API_KEY |
      | - Если PIN нет: валидирует формат x-gemini-api-key      |
      | - Не сохраняет ключ в файлы, базу или логи             |
      +----------------------------+----------------------------+
                                   |
                                   v  (HTTPS SSE stream)
               +---------------------------------------+
               |  generativelanguage.googleapis.com   |
               +---------------------------------------+
```

## 📡 API Эндпоинты

- `GET /` — Веб-интерфейс чата.
- `GET /ping` — Health-check для предотвращения сна (`{"status":"ok","uptime":...}`).
- `GET /api/status` — Диагностика доступных методов авторизации на сервере.
- `POST /api/chat` — Главный роут чата:
  - `stream: true` — стриминг SSE (`text/event-stream`).
  - `stream: false` — обычный JSON ответ (`application/json`).
