Gemini Proxy Chat

Ультралёгкий шлюз для Google Gemini API с поддержкой стриминга в реальном времени, собственного ключа (BYOK), файлов и автоматического переключения моделей.

🔑 Свой ключ (BYOK)
Укажите ваш собственный Gemini API Key. Ключ хранится локально в браузере и не передаётся посторонним.
🌊 Плавный Стриминг
Ответ поступает посимвольно в режиме реального времени. Вы можете прервать генерацию в любой момент.
📎 Файлы и Документы
Прикрепляйте скриншоты, фотографии, исходный код и текстовые файлы для мгновенного анализа.
Google Gemini 3.5 / 3.6 / 3.8 Flash & 2.5 Pro · Работает без VPN Стриминг активен (SSE)
Разработчик: @b6dmachine · Репозиторий: gustoa432-byte/Google-proxy-chat

⚙️ Настройки доступа и API

Ключ сохраняется исключительно в вашем браузере (localStorage) и отправляется на прокси только по защищенному протоколу. Ключи пользователей никогда не логируются.

Обычным пользователям PIN не нужен. Если вы развернули сервер на Render и задали ACCESS_PIN, ввод этого пароля предоставит доступ к серверному ключу владельца.

🧠 Системная инструкция (System Prompt)

Инструкция задает поведение модели для всех последующих сообщений в диалоге.

✂️ Обрезать историю

Обрезание удалит старые сообщения из контекста, освободит память и ускорит запросы к модели.
